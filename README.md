# NLP Research

An end-to-end NLP research project for building a **voice-driven AI assistant** that can understand multilingual speech and reason about objects in images.

---

## 1. Project Overview

This project explores two connected problems:

1. **Hearing & Understanding** (Module 1) — How do we take a voice command in *any* language and extract the user's intent, the object they are looking for, and its attributes?
2. **Dataset Preparation** (Module 2) — How do we prepare the image and referring expression data that a model will eventually use to find objects?

Together, these modules form the research foundation for a system where a user could say *"where is my black bottle?"* in Hindi, and the system would understand the request and visually locate the object.

## 3. Modules

### Module 1 — Hearing & Understanding

Records a voice command from the microphone, sends it to the **Sarvam AI Saaras v3** cloud API for multilingual speech-to-English transcription, then parses the English text locally using **spaCy** to extract intent, object, and attributes.

- Supports any language Sarvam AI recognises (Hindi, Tamil, Bengali, and more)
- Includes a benchmarking tool: **Whisper Tiny** (local, CPU) vs **Sarvam AI** (cloud)
- 67 unit tests covering all core modules

👉 See [module-1/README.md](module-1/README.md) for setup and usage.

### Module 2 — Dataset Inspection & Preprocessing

Three Jupyter notebooks that load the **COCO 2014** image dataset and **RefCOCO** referring expressions dataset, clean the data, and produce exploratory analysis outputs.

- 82,783 COCO training images
- 604,906 object annotations across 80 categories
- 267,568 RefCOCO referring expressions

👉 See [module-2/README.md](module-2/README.md) for notebook order and dataset setup.

## 4. Setup

### Module 1

```bash
cd module-1/

# Create and activate virtual environment
python -m venv venv
.\venv\Scripts\Activate.ps1       # Windows
# source venv/bin/activate        # macOS / Linux

# Install dependencies
pip install -r requirements.txt

# Download spaCy English model
python -m spacy download en_core_web_sm

# Set up API key
cp .env.example .env
# Edit .env and paste your Sarvam AI key
```

### Module 2

```bash
# Install Jupyter and data science packages
pip install jupyter notebook matplotlib pandas numpy pillow

# Download datasets — see module-2/README.md for sources and directory layout
```

## 5. Datasets

> **Datasets are NOT included in this repository.**

The raw datasets are too large (~15 GB) to store on GitHub. They must be downloaded separately and placed in the correct local directories.

| Dataset | Size | Where to get it |
|---|---|---|
| COCO 2014 train images | ~13 GB | [cocodataset.org](https://cocodataset.org/#download) |
| COCO 2014 annotations | ~241 MB | [cocodataset.org](https://cocodataset.org/#download) |
| RefCOCO | ~176 MB | [github.com/lichengunc/refer](https://github.com/lichengunc/refer) |

**Expected directory layout after download:**

```
module-2/datasets/
├── coco2014/
│   ├── train2014/          ← JPEG images
│   └── annotations/        ← JSON annotation files
└── refcoco/
    └── refcoco/
        ├── instances.json
        ├── refs(unc).p
        └── refs(google).p
```

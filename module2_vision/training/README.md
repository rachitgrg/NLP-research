# Training — YOLOv8n fine-tuning (15 indoor classes)

Fine-tunes YOLOv8n on 15 COCO classes for the assistant. The current model and its results are recorded in `research/experiments/2026-10-20_yolov8n_15class_finetune/`.

| File | Purpose |
|---|---|
| `train.py` | `coco_processed.csv` → 15-class filter → image-level 80/20 split (seed 42, val ≤ 3,000) → YOLO labels + image hard links in `data/yolo_dataset/` → `dataset.yaml` → train → validate → `results_summary.txt` |
| `test_model.py` | quick check of `runs/train/weights/best.pt` on an image, the webcam, or the val set (writes `test_output/`, gitignored) |
| `run_training.bat` | Windows launcher: disables sleep, auto-retries with `--resume` |
| `job.sh` | SLURM job script for an HPC GPU node |
| `dataset.yaml` | generated by `train.py` (the absolute `path:` was edited by hand on 2026-10-21) |
| `results_summary.txt` | generated by `train.py`; the current copy was overwritten by a resume (see the experiment caveats) |
| `runs/` | Ultralytics output, including `train/weights/best.pt`, the app's default model (gitignored) |

Inputs (project root, gitignored; override with `DATA_DIR`): `data/processed/coco_processed.csv` (from notebook 02), `data/raw/coco2014/train2014/`. Base weights: `../weights/yolov8n.pt`.

```powershell
cd module2_vision\training
python train.py                              # 30 epochs, batch 8, 640 px, GPU 0
python train.py --epochs 50 --batch 16       # override any parameter
python test_model.py --image path\to\img.jpg
```

Needs `ultralytics`, `pandas`, `scikit-learn` and `tqdm` (root `requirements.txt`, "Training + notebooks"). **Retraining overwrites `runs/train/`.** Copy the old run aside first and record the new one as a new experiment in `research/experiments/`.

# Module 2 — Dataset Inspection & Preprocessing

> Part of the NLP Research project.
> This module loads, cleans, and explores the COCO 2014 and RefCOCO datasets.

---

## What This Module Does

This module prepares two large computer vision datasets for downstream model training:

1. **COCO 2014** — A large image dataset with object annotations and captions.
2. **RefCOCO** — A dataset of short referring expressions (natural language phrases that describe a specific object in a COCO image, e.g. *"the man on the left"*).

The notebooks load the raw data, clean it, verify its integrity, and produce analysis outputs.

---

## Why This Module Exists

Before training any model that connects natural language to images, you need clean and well-understood data. This module answers:

- What does the raw dataset look like?
- Are there any broken or invalid entries?
- What are the statistics (categories, sizes, expression lengths, vocabulary)?
- What is the relationship between COCO and RefCOCO?

## Important Files

| File | What It Does |
|---|---|
| `01_dataset_inspection.ipynb` | Loads raw COCO and RefCOCO files. Verifies counts (82,783 images, 604,907 annotations, 50,000 RefCOCO expressions). Checks 100% cross-reference integrity. |
| `02_data_preprocessing.ipynb` | Flattens nested JSON to rows. Removes 1 invalid bounding box. Removes 16,852 duplicate expressions. Saves clean CSVs. |
| `03_eda.ipynb` | Deep exploratory analysis. Generates category distribution plots, bounding box size analysis, expression length stats, word frequency charts, and data quality audit. |
| `MODULE_2_WORK_SUMMARY.md` | A plain-language summary of everything the notebooks produced — useful to read without re-running the notebooks. |
| `parse_nb.py` | Development utility: reads a `.ipynb` file and dumps all cell code and outputs to a plain text file for quick review. |

## How to Run

Run the notebooks **in order** (01 → 02 → 03). Each notebook depends on the outputs of the previous one.

### Step 1 — Set up the datasets

Place the datasets in the expected directories:

```
module-2/datasets/coco2014/train2014/         ← COCO 2014 training images
module-2/datasets/coco2014/annotations/       ← COCO 2014 annotation JSON files
module-2/datasets/refcoco/refcoco/            ← RefCOCO pickle and JSON files
```

See the **Dataset Requirements** section below for download instructions.

### Step 2 — Install dependencies

```bash
pip install jupyter notebook matplotlib pandas numpy pillow
```

### Step 3 — Open and run the notebooks

```bash
cd module-2/ipynb/
jupyter notebook
```

Then run the notebooks in order.

## Key Findings (from the notebooks)

- **COCO 2014 Train**: 82,081 unique images, 604,906 annotations across 80 categories
- **RefCOCO**: 19,994 unique images, 267,568 referring expressions
- **Category imbalance**: "person" makes up 30% of COCO annotations and 50% of RefCOCO expressions
- **Expression length**: Average 3.6 words (median 3.0) — very short phrases
- **Top spatial terms**: "left" (63,060 occurrences), "right" (62,326 occurrences)
- **Data issues fixed**: 1 invalid bounding box removed, 16,852 duplicate expressions removed

## Limitations

- Only COCO 2014 **training split** is used. Validation images are not included.
- Only the **UNC** and **Google** RefCOCO splits are used (not RefCOCO+ or RefCOCOg).
- The `test` split label from the Google source is flagged by the data quality audit but is not an actual error — it is a known characteristic of the dataset.
